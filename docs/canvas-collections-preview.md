# 无限画布、组合歌单与试听预览

最初的独立预览基于 1.2.3 的来源图标与悬浮歌词修复提交 `900b552`。经确认后已于 2026-11-18 合入线上 1.2.5、搜索排序、蓝黄动效和下载帮助，并发布为网页 1.2.6；没有重新打包原生客户端。实际发布范围和验证见 [网页 1.2.6 发布记录](releases/v1.2.6.md)。以下为功能设计与预览验证记录。

## 画布操作

拖动空白处平移，滚轮移动，Ctrl / Command + 滚轮缩放；手机双指移动和缩放。左下角提供缩放和查看全部。每个用户在本机保存自己的视角，共享物件的位置独立保存为世界坐标，旧物件无需迁移。新物件出现在当前视口附近。

缩放范围为 20%–250%，手机初始至少 65%；世界坐标范围 ±1,000,000。原有共享画布容量仍为 200 个物件，每人 30 个。移动后的物件保持在最上层。

轻点唱片试听，再点一次或点击试听状态停止。专辑、歌单随机选择其中一首可播放的歌；长按拿起也会试听，唱片旋转并有轻微装饰律动。律动不是 BPM 或实时音频分析。减少动态效果的系统设置会关闭新增律动。

试听先暂停原播放器，结束、失败或离开页面后从原位置继续，不改变原队列、不增加试听历史、不领取画布物件。用户主动切歌或恢复主播放优先于试听。一起听模式暂不支持画布试听，避免改动房间的共同播放状态。

网易云优先使用平台 `song_chorus` 返回的副歌标记，最长播放 15 秒。没有标记时，或 QQ 歌曲，使用歌曲约 35% 处的 15 秒片段，界面显示“片段试听”，不声称它是实际高潮。播放沿用既有会员和版权权限。

拖到底部后继续走原有的正式追加队列逻辑；成功领取后物件从共享画布消失，播放列表自动展开。专辑和歌单跳过吞唱片动画，单曲保留动画及音效。

## 歌单作为文件夹

自己的歌单支持“放入专辑 / 歌单”。专辑、外部平台歌单保存为只读快照；本站歌单保存引用，内容随原歌单变化。只有原拥有者可以编辑自己的歌单，其他用户保持只读。移出文件夹只移除父引用。

展开文件夹可查看子文件夹和直接歌曲，播放整个父歌单时按加入顺序展开并按录音去重。自己的子歌单提供编辑原歌单入口。已被删除、私密化或撤回公开主页权限的他人歌单不再提供内容。

新增独立 `playlist_folders` 表，不重写旧 `playlist_songs`。添加操作在事务内拒绝循环，递归展开最多 16 层。每个歌单最多 100 个子文件夹，新放入时组合歌曲上限 1000 首。被引用歌单后来增长时仍完整读取，避免导致整个音乐库无法访问，也不静默截断；现有播放队列和画布整包分享仍有各自的 500 首限制。

## 网易云与 QQ 歌单导入

“我的”和音乐库提供导入入口。粘贴公开分享链接，预览名称和歌曲数量，再确认建立自己的可编辑歌单。保留平台来源和源顺序，重复录音只保留第一项。与“放入只读歌单”分别对应复制歌曲和保存文件夹快照。

支持网易云完整、hash 分享链接与 QQ 的 playlist / taoge 链接；允许列表内的 HTTPS 短链接最多解析四跳，每一步重新验证域名。HEAD 不返回重定向时尝试 GET。不接受任意 URL、自定义端口或链接中的凭据。

一个外部歌单最多导入 1000 首，使用平台分页并检查完整性，读取不全不创建歌单。网易云继续遵守原项目关于私人歌单、喜欢列表和绑定管理员个人歌单的访问限制。此预览不实现普通用户绑定各自平台账户，也不保证可导入私密歌单。确认导入会重新读取来源，以确认时的内容为准。

QQ 适配 NAS 现用 QQMusicApi v0.9.0 的 `GET /songlist/{id}/detail?num=100&page=N`，读取 `data.info.title`、`data.info.picurl`、`data.total` 与 `data.songs`。生产使用原有 `QQMUSIC_URL` 配置。

## 验证记录（2026-11-17）

- `npm test --prefix web`：28 个测试文件、181 项通过，包括坐标变换、导入来源限制、QQ 分页、引用权限撤回、循环原子拒绝、只读专辑、原拥有者编辑权、嵌套直接歌曲、父歌单后续增长、真实副歌与片段回退。
- 独立 Edge 无头浏览器：桌面平移缩放、共享坐标不被视角改变、快速试听切换仅一个音频发声、试听结束原位继续、不领取试听物件、长按试听、整包追加保留原队列、跳过整包吞入动画、领取后消失。
- 390×844 手机浏览器：双指缩放、初始 65% 视角、实际触摸长按试听与移动、文件夹横向不溢出、导入预览 Sheet；两组检查均没有浏览器运行时错误。原生 Android / Windows 客户端安装包尚未构建验证。
- 真实公开源验证：QQ 歌单 `9082901147` 共 111 首，网易云 `3085577764` 共 50 首；完整导入独立本地 SQLite，核对数量、顺序和可编辑属性。没有向生产歌单写入数据。
- 网易云真实副歌标记查询：`21178262` 返回 83.988–108.404 秒，`186016` 返回 84.498–142.301 秒。浏览器暂停恢复测试使用自行合成的 28 秒 WAV，不将它作为实际会员音源可播放的证据。
- Next 生产构建完成代码编译、类型检查、静态页生成。Windows 本机的依赖目录为工作树 Junction，standalone 拷贝阶段出现创建符号链接 `EPERM` 告警；本次未交付或部署该打包目录，正式发布需在部署构建环境再次验证完整产物。

开发专用 `/canvas-preview` 仅在 development、显式预览标志、合法临时预览 token 和 localhost Host 同时满足时可用；生产始终返回 404。测试数据和预览会话位于工作树以外的独立目录，不进入仓库。
