你可能想知道

需要安装才能听歌吗？+

不需要，直接打开网页版即可。在支持的浏览器中，也可以把网站安装为 PWA，添加到桌面或主屏幕。

每次更新，都需要重新安装吗？+

网页功能随服务端更新，可在「设置 → 关于」检查并应用更新。客户端原生能力升级时才需要安装新版；Android 的后续安装包也可从设置里检查下载。

可以和朋友怎么一起听？+

添加好友后，在「一起听」或聊天中发出邀请。接受后，从发起人的队列开始共同播放，双方都能添加、删除和切换歌曲，也能分享歌曲与公开歌单。
