# QQ 音乐与网易云双音源

歌曲搜索同时查询两个平台。确认是同一录音时合并为一行，并显示两个来源图标。歌名、歌手集合、专辑与版本必须一致，时长差不超过 2 秒；多个同样符合条件的候选、资料缺失、现场、翻唱、伴奏、重制等版本不自动合并。不同平台的专辑、歌手链接保持各自来源。首版的专辑/歌单搜索仍使用网易云。

播放器中可以指定平台；个人设置提供自动、网易云优先和 QQ 音乐优先。指定平台失败会显示该平台错误，自动模式才会尝试同一录音的另一来源。切源保留播放进度和暂停状态，歌词跟随实际播放来源。QQ 的标准 MP3、320 kbps MP3 和无损 FLAC 分别使用 QQMusicApi 的文件类型 13、12 和 7；不接收加密或试听文件。

旧网易云歌曲继续使用原数字 ID，QQ 歌曲使用 `qq-MID`。新增 `music_sources` 表记录对应关系，不重写原收藏、歌单、历史或画布。收藏与歌单按录音去重，删除任一来源会同时删除对应的收藏关系；播放队列保留请求的歌曲 ID、顺序与主动重复。音频缓存按实际平台歌曲 ID 隔离。

## 服务器配置

适配器使用 L-1124/QQMusicApi v0.9.0。将它作为仅服务器可访问的独立服务运行，关闭其公开凭据管理接口，避免把服务直接暴露到公网。设置 Web 容器环境变量：

```dotenv
QQMUSIC_URL=http://qqmusic:8080
```

Web 容器与 QQ 服务需要能通过 Docker 网络互相访问。在管理后台的「音源账号」里分别登录网易云与 QQ 音乐；QQ 支持 QQ、微信扫码。扫码结果只保存至 `DATA_DIR/qq-session.json`（0600），不会发给普通用户。不要把此文件或真实环境配置加入代码仓库、镜像或日志。未设置 `QQMUSIC_URL` 时继续使用原网易云功能。

QQ 播放权限在音频加载时验证；目录中的会员标记不等于当前账号拥有权限。首版没有可靠的独立 QQ 下载授权接口，因此 QQ 独有歌曲只提供在线播放；有对应网易云来源的歌曲仍走网易云独立下载授权接口。平台会员权限不能互相替代。

## 验证

新增身份匹配、跨页去重、歧义版本、缓存来源、手动/自动切源、权限、源服务故障和凭据隔离测试。另在独立数据库与容器中验证双源完整音频的 Range 响应、歌词、收藏、歌单、画布领取和重复队列恢复；使用独立无头浏览器检查桌面与 390px 手机界面及切源进度，不使用真实用户的客户端会话。
