# 播放定位、一起听分享与首次介绍

日期：2026 年 11 月 18 日。网页功能更新，不改变已发布客户端安装包的版本和下载配置。

播放列表标题旁和歌曲列表上方提供定位当前歌曲。滚动只影响最近的滚动容器，不切歌，不改变进度和队列。队列根据当前播放索引定位，普通列表兼容同录音的来源别名；当前歌曲不在列表时按钮禁用并提供说明。

一起听聊天内的音符按钮增加“我的歌单”，通过当前用户拥有者接口读取，兼容私密歌单和喜欢列表。歌曲可以点击发送，也可以用鼠标拖动、触屏长按拖至好友头像或当前聊天。悬停显示收件人，松开发送一次；拖到无效区域、取消、Escape、窗口失焦或切换页面不发送。歌曲分享继续使用既有好友权限与歌曲解析接口，不发送设备文件。

首次介绍覆盖播放栏、播放队列、歌曲列表、一起听、音乐库和搜索。轻量提示指向对应控件，支持跳过、上一步、下一步和设置中重看。完成状态以用户和设备为单位保存；新安装提示、更新公告或弹窗出现时顺延，画布沿用已有箭头引导。

验证包含现有 Web 测试和 TypeScript；独立模拟账户的浏览器验证覆盖桌面鼠标、手机真实触摸长按、正常滚动、接收人切换、无效区域、Escape、发送失败与重试、长列表定位、重复队列项、提示重看及账号隔离、深色和 320px 小屏幕。浏览器分享测试仅写入本地模拟接口，不给真实好友发送测试消息。
