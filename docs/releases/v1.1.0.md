## 使用

- 在我的歌单卡片点加号，或详情页点“加入播放列表”；电脑可拖动，手机可长按后拖到底部。
- 画布音乐拖到底部追加到队尾，保留当前播放。便签和图片可通过画布工具菜单添加。
- 播放器和个人设置可调节音量、静音。
- 新客户端的完整播放器支持桌面歌词，也可在原悬浮歌词中选择“移到桌面”；Android 第一次开启时需授予显示在其他应用上层的权限。
- 网页功能刷新后可用；系统悬浮歌词需安装新客户端。
