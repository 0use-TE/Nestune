# Nestune 1.1.1

发布日期：2026-11-17。功能说明见 [更新记录](../../CHANGELOG.md)。

## 本次变化

- Windows 歌词锁定只固定位置，背景、解锁和关闭按钮保持可用；锁定时工具栏常显，兼容旧版锁定状态。
- 主播放器增加锁定状态的解锁和关闭入口；旧 Windows 客户端提供下载升级提示，避免误用 WebView 的浏览器画中画接口。
- 歌手页「播放全部」读取完整曲库，最多取前 500 首中的可播放歌曲；保留热门歌曲按钮，支持取消，加载失败时保留原队列。
- 网站和客户端内发布本次更新公告。Android 继续使用 1.1.0/code 6，无需重装。

## 验证

- Web：19 个测试文件、127 项测试及 TypeScript 检查通过。
- Windows：两项 Rust 来源/数据边界测试、歌词渲染器交互测试通过；隔离隐藏的原生窗口验证旧锁定状态恢复、解锁、再次锁定、禁止拖动、背景切换和锁定时关闭，并读取 Windows 窗口样式确认鼠标穿透未启用。未自动操作用户桌面或断言实际鼠标位移。
- Windows release/NSIS 构建成功，程序版本资源为 1.1.1。
- 服务端使用隔离数据库预检歌手分页、权限元数据、鉴权和安装包下载；上线保留原数据库文件及音频 worker。

歌手曲目目录匿名读取，避免包含绑定账号的私人云盘文件；可播放权限独立使用绑定音源账号读取。
