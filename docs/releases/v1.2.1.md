# Nestune 1.2.1

日期：2026-11-17。网页版本为 1.2.1，新客户端构建源码也已准备为 1.2.1。

## 最近更新

- 1.1.1：修复 Windows 歌词锁定后无法操作，提供旧客户端升级提示；歌手曲库分页播放全部。
- 1.2.0：QQ 音乐与网易云歌曲搜索、录音合并、来源标识、自动优先与手动切源；歌词跟随实际音源。
- 1.2.1：YRC/QRC 逐字时间驱动的蓝黄流光。每句起始颜色、方向和速度变化，同一次播放中暂停和回拖保持稳定。只有 LRC 的歌曲使用估算扫色。

播放器、应用内浮窗和浏览器画中画刷新后可用。Windows 本地歌词页和 Android 原生歌词绘制源码已支持相同效果，系统独立浮窗需安装下一次构建的客户端。

已上线的音乐库收藏卡片和拖动排序、我的喜欢整批加入歌单与整份播放、来源选择弹层和 ISRC 匹配改动也已同步到本次构建源码。

## 验证

- Web：25 个文件、162 项测试与 TypeScript 检查通过；覆盖 YRC/QRC、翻译、音源回退、Unicode、逐字停顿、消息大小、随机配色的稳定性与分布。
- 浏览器：1366 / 390 / 320 px 下的播放、暂停、回拖、长句换行、浮窗拖动、关闭、原版对比和减少动态效果通过；原有 QQ 搜索与保留暂停/进度的切源检查通过。
- Windows：Rust 测试、debug 构建、隔离隐藏窗口的锁定恢复/解锁/背景/关闭检查通过；本地 HTML 的真实 DOM 检查验证逐字停顿、回拖复位和暂停流光。
- Android：`compileUniversalReleaseKotlin` 通过，包含原生逐字绘制类与悬浮窗接线。此轮未重新安装到实体手机或发布新 APK。
- 本地演示入口 `/lyrics-preview` 需要 `NESTUNE_LYRICS_PREVIEW=1`；正式部署不设置该开关，入口返回 404。

当前安装包下载与校验记录见 [1.1.1](v1.1.1.md)。新包构建发布后再更新下载元数据；网页更新不会提前宣称新客户端已可下载。
