# Nestune 1.2.1

日期：2026-11-17。网页、Windows 和 Android 版本均为 1.2.1。客户端已构建并发布到 [NAS 下载页](https://nestune.0use.net:8443/downloads)，入口保持为 `https://nestune.0use.net:8443/`。

## 最近更新

- 1.1.1：修复 Windows 歌词锁定后无法操作，提供旧客户端升级提示；歌手曲库分页播放全部。
- 1.2.0：QQ 音乐与网易云歌曲搜索、录音合并、来源标识、自动优先与手动切源；歌词跟随实际音源。
- 1.2.1：YRC/QRC 逐字时间驱动的蓝黄流光。每句起始颜色、方向和速度变化，同一次播放中暂停和回拖保持稳定。只有 LRC 的歌曲使用估算扫色。

播放器、应用内浮窗和浏览器画中画刷新后可用。Windows 本地歌词页和 Android 原生歌词绘制支持相同效果，系统独立浮窗需安装本次发布的 1.2.1 客户端。

已上线的音乐库收藏卡片和拖动排序、我的喜欢整批加入歌单与整份播放、来源选择弹层和 ISRC 匹配改动也已同步到本次构建源码。

## 验证

- Web：25 个文件、164 项测试与 TypeScript 检查通过；覆盖 YRC/QRC、翻译、音源回退、Unicode、逐字停顿、消息大小、随机配色的稳定性与分布。
- 浏览器：1366 / 390 / 320 px 下的播放、暂停、回拖、长句换行、浮窗拖动、关闭、原版对比和减少动态效果通过；原有 QQ 搜索与保留暂停/进度的切源检查通过。
- Windows：3 项 Rust 测试、release/NSIS 构建通过；发布版使用隔离隐藏窗口验证新 HTTPS 入口、1.2.1 版本、歌词 IPC 与远程权限边界。本地 HTML 的真实 DOM 检查验证逐字停顿、回拖复位、暂停流光和锁定/解锁/背景/关闭。
- Android：通用 release APK 构建通过；v2/v3 签名、原证书、包名、1.2.1/code 7 与 16 KiB 对齐检查通过；三个架构的原生库均包含新入口。本次未在实体手机上安装验证。
- NAS：三个公网下载文件的完整 SHA-256 与本地一致；下载页、新版更新元数据、HTTP Range 和旧版历史记录检查通过。发布前备份原索引和更新元数据，发布仅修改安装包与下载索引。
- 本地演示入口 `/lyrics-preview` 需要 `NESTUNE_LYRICS_PREVIEW=1`；正式部署不设置该开关，入口返回 404。
