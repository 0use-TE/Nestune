# Nestune 1.2.2

日期：2026-11-17。网页与三大桌面客户端为 1.2.2，Android 保持 1.2.1 / code 7。桌面安装包已发布到 [NAS 下载页](https://nestune.0use.net:8443/downloads)，所有客户端入口保持 `https://nestune.0use.net:8443/`。

## 更新内容

- Windows x64 与 ARM64 都有安装版和便携版，下载页明确显示用途；ARM64 更新接口返回对应架构安装包。
- Windows、Linux、macOS 提供原生系统托盘／菜单栏图标。关闭主窗口后继续播放；菜单支持打开／隐藏窗口、播放／暂停、上一首／下一首、开关桌面歌词和退出。Windows 左键恢复窗口，macOS 菜单栏和 Dock 都能重新打开。
- Linux 需要桌面提供 StatusNotifierWatcher/AppIndicator 托盘区域。没有托盘宿主时，关闭窗口正常退出，避免进程隐藏后无法操作。DEB 声明托盘库依赖，AppImage 包含该库。
- 音乐库移除排序图标，长按卡片后拖动即可实时交换，并显示动画，松开后保存。移动端保留正常滑动浏览。
- 歌单和管理页面的下拉框统一深浅主题、键盘操作和弹层位置。
- Web 更新内容同时出现在新版提示、设置 → 关于，以及待更新提示。保留历史说明；`/api/release-notes` 不缓存，让旧网页在刷新前读取新版说明。关于页面分别显示网页和客户端版本。

网页改动刷新后使用，系统托盘需要安装 1.2.2 桌面客户端。
