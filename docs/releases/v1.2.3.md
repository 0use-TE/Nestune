# V1.2.3 · 来源图标与悬浮歌词锁定修复

- 恢复网易云和 QQ 音乐来源 SVG 图标，双来源同时显示，切源菜单保留平台名称。
- 安卓锁定仅禁止拖动，工具栏保持可点；旧锁定状态启动后可直接解锁。
- Windows 流光歌词不再遮挡按钮；拖动通过原生命令校验，锁定时拒绝移动。
- 主应用保留解锁与关闭入口。

## 验证

- Web：167 项测试、TypeScript 检查。
- Windows：渲染器测试、Rust 测试，隐藏原生窗口验证锁定、解锁、位移保护、背景及关闭。
- 浏览器以长句歌词复现旧版按钮遮挡，验证多种窗口尺寸下三个按钮命中与交互。
- 安卓：独立模拟器真实点击锁定、解锁、背景、关闭；验证拖动、旋转、后台时钟、关闭状态回传及子框架隔离。
- Android 1.2.3/code 8 使用原签名，包含 arm64-v8a、armeabi-v7a、x86_64。
- 本轮安装包范围为 Windows x64 与 Android；其他架构及系统保留 1.2.2 下载，不宣称已修复。

系统浮窗修复需要覆盖安装新版并重启客户端；仅刷新网页不能更新原生浮窗。
