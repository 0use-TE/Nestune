# V1.2.5 · 悬浮歌词穿透与长句滚动

Windows x64 和 Android 需要安装本版，网页更新只提供公告，不会替换旧客户端的系统浮窗。

- Windows 闭锁/开锁 SVG 按原生状态切换，请求未完成时不重复提交。
- Windows 锁定时歌词窗口忽略鼠标事件，独立的小工具窗口保留解锁、背景、关闭，位置随歌词窗口和缩放调整。
- Android 锁定时在独立的可交互悬浮窗中显示工具栏，文字窗使用 NOT_TOUCHABLE；Android 12+ 降低文字窗整体不透明度，满足系统的安全穿透条件。解锁后恢复正常拖动与按钮自动隐藏。
- 长歌词改为单行横向滚动，按当前歌词的时间段推进，开头与结尾留停顿。暂停不继续移动，回拖和换句同步位置，保留逐字流光。Android 翻译使用循环滚动。
- 可从 1.2.4 的客户端更新入口下载并打开安装程序，旧版保留手动下载。

## 验证

- Windows 渲染器测试、原生窗口样式与锁定/解锁/位移保护/背景/关闭测试。
- 280px、620px 真实浏览器验证长句末尾、暂停、回拖及锁图标切换。
- 安卓独立模拟器验证锁定后真实点击传到下面的页面、解锁恢复拖动、旋转、长歌词滚动及暂停/回拖复位。
- 正式安卓安装包沿用原签名，包含 arm64-v8a、armeabi-v7a、x86_64；其他架构/系统保留原客户端下载。
