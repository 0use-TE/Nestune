# 网页 V1.2.6 · 2026-11-18

无限画布、专辑和歌单组合、网易云与 QQ 公开歌单导入，以及画布唱片试听。刷新页面或重新打开客户端即可使用；原生 Windows x64 和 Android 安装包继续使用 1.2.5，本次没有重新打包客户端。

## 功能

- 空白平移、滚轮移动、Ctrl / Command + 滚轮缩放，手机双指操作，以及缩放和查看全部按钮。视角各自保存在本机，物件世界坐标在所有用户之间共享。
- 自己的歌单可以包含专辑和其他歌单，专辑、外部平台快照和别人的内容只读，自己的歌单可继续编辑。权限实时复核，拒绝循环引用；移出不删除原内容。
- 在「我的」或音乐库粘贴网易云、QQ 公开歌单分享链接，预览并确认后复制为可编辑歌单。保留歌曲来源和顺序，每次最多 1000 首；读取不完整则不写入。
- 轻点或长按画布音乐试听，专辑和歌单随机选曲。网易云优先使用平台副歌标记；QQ 和缺少标记的歌曲使用约 15 秒片段。唱片旋转并轻微律动，试听结束恢复原播放位置与暂停状态，不改变队列。
- 拖到底部仍接到播放队列末尾，成功领取后物件消失并展开列表。专辑和歌单跳过唱片机吞入动画，单曲保留原动画。

## 范围

歌曲播放继续遵守音源账号的会员、购买和版权权限，不保证任意私密歌单可导入。一起听时暂不提供画布试听，避免影响房间共同播放状态。律动为装饰动效，不是节拍分析。画布仍保留 200 个共享物件、每人 30 个物件的原有限制；播放队列和整包画布分享保持 500 首上限。

## 发布验证

保留线上 1.2.5 的客户端更新、悬浮歌词穿透和长句滚动，以及后续搜索排序、蓝黄动效和下载帮助。正式切换前备份源文件与数据库，用独立数据库在 NAS 构建和预检；生产继续挂载原数据库和音源配置。详细验证结果在发布完成后补入本记录。

此前独立预览通过 181 项测试及桌面、390px 手机浏览器检查，使用真实公开歌单验证 QQ 111 首和网易云 50 首的完整导入与顺序。详见 [功能说明](../canvas-collections-preview.md)。
