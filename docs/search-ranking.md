# 歌曲搜索排序

歌曲搜索并行请求网易云和 QQ 音乐，各平台每次读取一页，随后合并已识别为同一录音的来源，再统一排序。上传歌曲参与同一批排序，不再固定置顶。专辑、歌手和歌单搜索保持原有上游结果。

排序结合歌名完整匹配、明确输入的歌手、各平台原始名次和版本关键词。平台名次采用倒数衰减，取最佳来源为主，另一来源给少量一致性加分。歌曲属于哪个平台、接口先后返回、能否免费播放均不决定优先级。

默认对未指定的现场、伴奏、DJ、翻唱、加速等版本适当降权；用户明确搜索对应版本时优先匹配。完整专辑资料有少量加分，精选合集有少量降权。这些均是启发式信号，不代表经过认证的原唱标记，标题中的“原唱：某某”不作为歌手身份。

上传歌曲支持空格分开的多个关键词，每个词可分别匹配歌名、歌手、专辑等字段，继续遵守上传可见范围。

当前排序范围是每次已获取的候选批次，不预先读取所有上游搜索结果。加载更多继续按原偏移读取下一页、合并去重并追加，不打乱用户正在浏览的已加载列表。

这是一项网页服务更新，刷新搜索即可生效，无需重新安装客户端。
