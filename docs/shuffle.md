# 随机播放

旧实现每次从当前歌以外的队列条目中等概率抽选，允许 A → B → A。重复加入的歌曲也会占据多个抽选位置。

新实现保留当前列表本轮已选择的录音集合，每次从本轮未选择的不同录音中等概率抽选。集合耗尽后开启新轮，第一首排除上轮最后一首；列表只有一种录音时继续播放该曲。同一录音重复添加或存在已识别的跨平台来源不会增加权重。

主动点选的歌曲记入本轮，失败后切过的曲目也会先略过，避免反复卡在同一首。更换整份播放列表开启新轮；追加曲目进入当前待选范围，删除曲目时清理状态。随机模式上一首按实际播放记录回退，回退后下一首沿历史前进，手动点选则从该位置建立新分支。

个人队列同时保存模式与轮次状态，刷新后可以继续；设备文件只在本机参与，持久化在线队列时过滤设备条目。共同队列的轮次由服务端保存并在事务内推进，双方读取同一结果，过期的主机自动切歌请求不会再次消耗轮次。原有队列 JSON 兼容，不更改数据库结构。

验证包含固定随机数下多轮不重复、重复行与来源别名、大列表、新增删除、历史回退、JSON 恢复、账号隔离、旧客户端和共同队列并发版本控制；另使用桌面与手机尺寸的真实浏览器操作验证下一首、上一首及刷新恢复。
